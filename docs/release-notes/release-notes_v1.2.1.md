# パスワード生成ツール v1.2.1 リリースノート

- **バージョン:** v1.2.1
- **リリース日:** 2026年10月18日
- **変更元バージョン:** v1.2.0

## 概要

v1.2.1 では、記号のテキスト入力による除外処理の不具合を修正し、パスワード生成で使用する乱数の安全性を強化しました。

## 不具合修正

### 記号の除外処理を修正

「記号あり」→「テキスト入力」→「除外する」を選択した際、入力した一部の括弧が除外対象として正しく認識されない問題を修正しました。

- `( )` や `[ ]` のように括弧内が区切り文字（空白など）となる場合、括弧を囲み表現として誤解析しないよう変更しました。
- `< > ( ) [ ] \ , ; : " ~` などを空白区切りで入力した際、指定した記号を除外できるようになりました。
- `(@)` や `"@"` のように、記号を括弧・クォートで囲む既存の入力形式は引き続き利用できます。

## セキュリティ改善

### 暗号学的に安全な乱数生成へ変更

パスワードの文字選択とシャッフル処理で使う乱数を、`Math.random()` から `crypto.getRandomValues()` に変更しました。

- `secureRandomInt()` を追加し、暗号学的に安全な乱数に基づいて整数を生成するようにしました。
- 値を範囲へ変換する際、棄却サンプリングによって剰余バイアスを回避します。
- `pickRandom()` と `shuffleArray()` を、新しい乱数生成処理を使用するよう更新しました。

これにより、生成するパスワードの乱数の予測困難性を向上させました。

## 互換性と利用方法

- パスワードの文字種、文字数、生成個数、コピー、ダウンロードなどの操作方法に変更はありません。
- HTML と CSS の機能・レイアウト変更は必要ありません。
- バージョン表示を管理している場合は、`index.html` の `<meta name="version" content="1.2.0">` を `1.2.1` に更新してください。
